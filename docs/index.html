SAP CPQ Automation

Python scripts for bulk SAP CPQ category and product management via REST API.

convert_json_to_excel.py

Converts scraped product JSON data into CPQ-importable Excel format with proper system IDs and category mappings.

cpq_category_uploader.py

Bulk uploads categories, attributes, and products to SAP CPQ via the REST API with token auth and retry logic.

cpq_link_categories.py

Two-pass category linker: fetches all category IDs first, then updates parent references in bulk.
